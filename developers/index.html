Para desarrolladores y agentes

API de Intelix — documentación y sandbox.

API pública de solo lectura, sin autenticación, versionada por URL. Pensada para que un desarrollador o un agente de IA la integre sin pedir permiso.

openapi.json llms.txt sitemap.xml

Quickstart

Un único endpoint público, sin API key. Probalo directo desde la terminal:

curl https://intelix.com.ar/api/v1/productos.php

Autenticación

No hace falta API key ni token: el catálogo es información pública (sin precios ni stock). Si en el futuro publicamos endpoints con datos privados, vas a necesitar una API key emitida por nosotros — escribinos a contacto@intelix.com.ar si tu integración lo requiere.

Endpoints

MétodoEndpointDescripción
GET/api/v1/productos.phpCatálogo público de productos y servicios activos.

Esquema completo, incluyendo errores, en openapi.json (OpenAPI 3.1).

Versionado y deprecación

La API se versiona por path: la versión actual es /api/v1/. Cambios incompatibles (renombrar campos, quitar endpoints) se publican bajo una nueva versión, /api/v2/, y nunca se aplican en caliente sobre v1.

Antes de retirar una versión, la respuesta incluye los headers Deprecation: true y Sunset: <fecha RFC 1123> durante un mínimo de 6 meses antes de darla de baja. Mientras una versión no tenga esos headers, es seguro integrarla sin miedo a que cambie sin aviso.

Errores

Todos los errores de la API (incluyendo rutas de /api/ inexistentes) devuelven JSON estructurado, nunca una página HTML:

{ "error": { "code": 404, "status": "not_found", "message": "No existe un endpoint en /api/foo.", "hint": "Consultá /openapi.json para ver los endpoints disponibles." } }
